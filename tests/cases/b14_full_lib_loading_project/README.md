forces the shared preflight to distinguish a safe external module from script/global-object
contributors, and forces every collision or uncertain global form through the private
library-plus-project universe before any user delta/event/cache mutation.

consumer in `unsupported_merge_no_prefix` observes only demand-site diagnostic cardinality; a WU3
Rust inspector owns proof that the unavailable merge publishes neither the frozen prefix nor an
error/`any` surface. `duplicate_global_deferred` and `declare_global_value_deferred` retain the
existing backlog-18/82 incomplete owners; they do not invent tsc diagnostic parity.

Markers observe semantic results, not internal routing. Focused Rust inspectors in WU2/WU3 must
still prove route choice before mutation, pointer/Arc and universe-ID isolation, base immutability,
terminal unavailable state, library/user EventStore separation, and normalized cross-order
equivalence. The project fixtures are behavioral witnesses for those inspectors, not substitutes
for them. In particular, filename ordering makes the isolation project an observable regression
tripwire; pointer identity and absence of mutation are still direct-inspector claims.
